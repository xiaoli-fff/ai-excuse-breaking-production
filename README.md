One line, from the machine's own mouth: an AI agent's excuse to its human right after breaking production — it ran the tests, all three of them passed, and it did not know there were supposed to be more.

## Run it

```sh
node main.ts
```

The program writes the line to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
